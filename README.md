# 余响航线 · 深海远征 v6

单人 2D 俯视角射击肉鸽：移动、瞄准、冲刺与自主瞄准分身，挑战随机海域和多首领战斗。

**在线游玩：https://biscuit19.github.io/CodexGame1/**

建议电脑、鼠标和键盘，1280×800 以上分辨率。首页右上显示“深海远征 / 06”；若看到旧版请 Ctrl+F5 刷新。兼容 v2/v3/v4/v5 存档，自动更新规则与商店价格。存档在当前浏览器，清除网站数据会删除进度。

## v6 更新

- **后期商店经济**：修复和救援随关卡、既往购买次数提价，刷新不会重置价格。首次购买示例（未叠加既往购买涨价）：第 1 / 15 / 20 / 25 关修复为 40 / 370 / 978 / 2613 星币，救援为 190 / 1334 / 3837 / 11577 星币。遗物价格也随关卡上升，高级遗物更贵。
- **36 件遗物与弱成长**：新增猎鲸契印、熔星反应炉、深潜核心、赤潮圣杯、逐星矛尖、镜海圣典、停潮沙漏、不熄灯塔。只在第 10/13 关后、金箱/首领奖励/后期商店等高级池中小概率出现；高级池约 10% 的抽取包含一件。满级遗物不再进入奖励池。池子耗尽时补入研修或其他奖励；商店满级货品也会替换，并合并重复的研修货架。
- **持续消费**：第 7 关起商店提供火力研修与船体研修，可重复购买，每次分别增加基础伤害倍率 0.8 个百分点或 2 生命上限，价格逐次增长。升级奖励和物资箱在遗物耗尽时也有研修。成长为线性，强度很小。
- **无尽压力曲线**：从第 16 关起，敌方额外血量每关乘 1.55、伤害每关乘 1.13。玩家武器最高 T7，经验收益逐渐降低，无尽生命扩容降为 +2。目标是第 20 关左右明显吃力、第 25 关极难，保持数值压力而非强制判负。三组自动玩家分别在第 21/24/21 关结束；真人结果会随构筑与操作不同。
- **奖励队列修复**：清场吸取后先处理升级与箱子奖励，箱内经验带来的升级和额外升级同样会在下一关之前完成，最后才出现下一关入口。旧存档中滞留的升级也会补领。所有升级、箱子、首领和清场奖励均可放弃并兑换 20–40 星币，保留当前武器；选择星币袋的收益始终更高。
- **更清楚的界面**：精简奖励、商店、教程提示，移除无效果的原型词条说明；星币金色、生命绿色、伤害蓝色，元素和武器特殊词条单独着色。构筑和暂停显示累计伤害（k），新产生的伤害统计排除过量伤害。
- **67 张原创物品图标**：透明 SVG 独立轮廓，使用金属、纸张、皮革、宝石的填色和明暗，替换奖励、构筑、商店与技能中的线框图标。生成源为 tools/icons.mjs，可用 `node tools/icons.mjs` 重新生成。
- **命中反馈**：增加短促撞击声、白色命中闪光、长条火花、受击摆动和轻微镜头反馈；减少震动选项会抑制镜头和受击摆动。

## v5 已有内容

- **三个独立存档槽**：从首页“选择存档”进入。退出、切换、暂停和每 10 秒自动保存到当前槽位；继续已有存档保留战斗、商店和待领奖励状态。新建空槽或明确点击“重开此存档”后才开始新游戏，其他槽位不受影响。旧单存档自动迁入槽 1。通关与结束结果保留在原槽，可重新进入通关记录继续无尽。存档存在当前浏览器中。
- **18 种武器骨架**：新增曙光切割器、双螺旋、破浪加速炮、星雷布设器、日冕环流、裂星母弹、天穹长枪、万象风暴。包括瞬发穿透光束、波形双弹、加速弹、感应雷、环形齐射、分裂追踪弹等不同攻击。新骨架从第 5 / 7 / 10 / 13 关分批解锁。
- **六档武器品质**：标准、稀有、史诗、传说、远古、神话。远古仅第 10 关后、神话仅第 13 关后出现。第 7 关起武器至少史诗，第 10 关起至少传说；后期箱子与清场奖励增加武器选项，商店同步改善。
- **10 种 Boss**：新加雷翼审判者、深渊炮舰、星轨织蛛、熔潮巨钳、时空牧星者；各有独立的动态矢量造型、多阶段攻击、红色预警和音效。最终双 Boss 保证种类不同。
- **战斗反馈与平衡**：增强命中粒子、暴击火花和光束特效；后期 Boss 血量降低约 30–40%，伤害随关卡提高，攻击保留可躲避的预警。

## 已有玩法

- **更短的航段**：普通敌潮刷新窗口 25–60 秒，最终关 90 秒。倒计时结束停止刷新，必须消灭全部敌人再过关；实际清场和首领战可超过刷新窗口。击败首领仍需清掉所有小兵。
- **最终双首领**：最后一关同时出现两位常规首领。后期小兵、悬赏逐渐增强，首领血量较上一版降低约 30–40%、攻击伤害提高；首领移动加快，增加分层弹幕、定向追击和更频繁的物理攻击。每种攻击有不同音效。
- **无尽模式**：每关至少一位首领，每三关增加一位，最多五位。刷新窗口按数量为 60、67.5、75、82.5、90 秒，多首领共享调整后的遭遇血量预算，避免单纯叠血拖长战斗。
- **明确的危险色**：敌弹与延迟攻击圈为红色，爆破中心是红色三角警告图案。小地图放大，敌人和首领标记更清晰。
- **清楚的装备信息**：商店武器标明稀有度、T 等级与每秒伤害，遗物标明品质；武器和遗物常规价格提高到 420 / 280 星币，商队折扣为 300 / 200。构筑页明确展示当前武器、单发伤害、射速、每秒伤害 和遗物列表。
- **更多物资**：物资箱可提供武器、遗物、经验、星币、治疗、生命上限、伤害校准、技能芯片与救援。金箱保证包含一项至少传说品质武器选择。满血、救援上限、校准上限等会影响可选池。
- **清楚的奖励来源**：大标题直接写“升级奖励”“物资箱奖励”“击败首领 · 航段清场奖励”，卡片以大字显示奖励类别。下一条航线由系统随机确定，关间可购物后直接出发。
- **自动收取动画**：清场后播放约 1.3 秒的金币、经验汇入角色动画，全部结算后再选奖励。初始拾取半径从 100 提高到 170，吸取中也能保存和恢复。
- **信标随机回报**：每座信标增加随机星币，并可能掉落普通箱或金箱；三座全亮保证金箱、100 星币和额外经验，还可能触发裂隙守卫或额外补给。占领仍需 3.5 秒。
- **17 类事件**：增加运宝卫队、共生双子、脉冲阵列、裂隙守卫、沉船金库、超载供能、陨星风暴。新增运宝者、护卫、双子、哨兵、裂隙守卫五种特殊变体。战斗事件在目标死亡后结束，不再空挂倒计时；限时悬赏仍保留逃离规则。
- **醒目的事件与技能 UI**：事件先在中央显示大标题，再移到左侧红字栏。冲刺和分身各有大图标、灰色冷却遮罩、恢复进度与就绪闪光。
- **23 首完整配乐**：来自 0 A.D. 的 15 首常规曲、5 首首领曲、3 首事件曲，按进度分组随机轮换、淡入淡出、统一响度。详情与许可见 [ASSET_CREDITS.md](ASSET_CREDITS.md)。

每秒伤害 是当前构筑的理论输出，不计暴击、穿透、爆炸、分身和临时事件增益，不能直接等同于实际战斗总伤害。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准 / 持续射击 | 鼠标移动 / 按住左键 |
| 冲刺 | Shift / 空格 |
| 分身（复刻移动、自主瞄准） | Q / 鼠标右键 |
| 宝箱 / 附近商店 | E |
| 中央商店 | 靠近后按 B |
| 暂停 / 构筑 | Esc / Tab |
| 选择奖励 | 鼠标 / 数字 1、2、3 |

设置可开启自动射击、辅助瞄准、减少闪光和震动，并独立调整音乐和音效。分身即便没有射击记录也会自主攻击。

## 下载与运行

源码在 `codex/echo-drift-delivery`，线上发布产物在 `gh-pages`。
下载 `release/echo-drift.zip`（GitHub 文件页 → Download raw file），解压后打开 `play.html` 离线游玩。离线版完整音乐已内嵌，单文件约 48.6 MiB。在线 Pages 使用约 158 KiB 的独立页面，按需加载当前音乐，不必先下载整个曲库。

浏览器限制本地 HTML 时，在解压目录执行 `npm start`，访问 http://localhost:4173/ 。仅运行游戏需 Node.js 20+，无需安装依赖。云环境目录：`/workspace/CodexGame1`。Pages 不依赖云端服务持续运行。

## 4.1 更新

清场时，所有未开的物资箱与金币、经验一起飞向角色，随后逐箱选择奖励，最后才进入航段奖励或通关画面。遗留收费箱在清场时免费领取，不会自动扣币。Boss 保证掉落黄金物资箱，最终双 Boss 的箱子也必须结算后才通关。自动拾取及待领取箱子均支持存档。

技能栏放在屏幕底部正中，增大图标与文字，冲刺明确显示空格 / Shift；奖励卡增加分类矢量图标，移除重复小标签，遗物层数置于名称右侧。高速追猎者事件改为 8–16 名敌人。

默认开启自动射击和辅助瞄准，可在“设置”中分别关闭。旧版设置首次更新时也会开启，之后保留玩家的开关选择。
