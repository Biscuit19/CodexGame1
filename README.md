# 余响航线 · ECHO DRIFT

一款完整的单人 **2D 俯视角射击肉鸽**。你是沉没记忆海中的拾光员：与复刻自己行动的回声并肩，在随机的航线上修复五座灯塔。

## 立即游玩

在 GitHub 的 `codex/echo-drift-delivery` 分支中，点击 **Code → Download ZIP** 下载整个项目；或打开 `release/echo-drift.zip`，点击 **Download raw file** 下载成品包。

**最方便：下载本目录的 `play.html`，用桌面版 Chrome / Edge / Firefox 打开。** 这是包含代码、画面和声音的单文件成品，无需安装依赖，也无需联网。

若浏览器限制打开本地 HTML，可使用下面的服务方式。请使用电脑、鼠标和键盘；推荐 1280×800 或更高分辨率，全屏体验更好。

### 在云环境或本机启动

```bash
cd /workspace/CodexGame1
npm start
```

服务监听 **4173 端口**，入口为 `/`，单文件版入口为 `/play.html`。当前 Codex 云环境没有已确认可供用户访问的公网或端口转发入口；建议从 GitHub 下载成品，在本机游玩。本机运行服务后可在浏览器打开本机的 4173 端口。运行只需要 Node.js 20+，不需要先执行 `npm install`。可用 `PORT=其他端口 npm start` 更改端口。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准、持续射击 | 鼠标移动、按住左键 |
| 折光冲刺 | Shift / 空格，短暂无敌 |
| 余响复写 | Q / 鼠标右键 |
| 打开物资箱 | 靠近后按 E |
| 暂停 / 继续 | Esc |
| 查看构筑 | Tab |
| 选择奖励 | 鼠标点击 / 数字 1、2、3 |

**余响复写**会循环复刻你最近 4 秒的移动与射击，基础持续 6 秒。提前边走边射，再召唤分身，能从不同方向交叉攻击。两个技能都有冷却，不消耗物资。

设置里可分别开启**自动射击**和**辅助瞄准**，也可调整声音、关闭环境音乐、减少震动与闪光。

## 这一局会遇见什么

- **5 片主题海域、15 个航段、5 位独立招式首领**，含完整通关结局。
- 每个航段基础 3 分钟，每第三段结束出现首领。纯战斗模拟约 48–49 分钟，加上探索、阅读和选择，目标总时长约 **1 小时**。
- **10 种枪械骨架 × 5 种元素 × 7 种词缀 × 4 种品质**。有散射、穿透、追踪、回旋与爆炸；传说枪械基础掉落概率为 2.5%，部分路线和遗物会改变掉落。
- **28 种可叠加遗物**：连锁电弧、死亡爆炸、环绕卫星、双重回声、引力漩涡、三相弹幕等。
- **9 类普通敌人**，含冲锋、狙击预警、召唤、自爆、旋转弹幕等；首领低生命时会进入第二阶段。
- **6 种随机事件、4 条分支路线**，以及每 24 秒交替的涨退潮。
- 默认“悠游航行”降低 32% 受伤伤害，有自然恢复、两次满血救援、升级与过关治疗。也可选择标准难度。

绿色星屑用于升级。站在信标光圈内 8 秒能获得经验、星币和生命修复；点亮当前航段的三个常规信标，再获一只物资箱。橙色区域和虚线是即将到来的攻击，请先躲开或冲刺穿过。

## 存档

每 10 秒、暂停、奖励选择和离开页面时自动保存。首页选择“继续航行”，可恢复战斗或尚未选择的奖励。开始新航行会覆盖旧存档，通关或救援耗尽会结束该局。

存档保存在**当前浏览器的本地存储**中，不上传服务器。请使用同一个浏览器、同一个地址/文件继续；清理网站数据或更换设备不会保留存档。单文件版与服务器版的存档各自独立。

## 开发与验证

```bash
npm ci --cache /tmp/echo-npm-cache --ignore-scripts --no-audit --no-fund
npm run check          # JavaScript 语法检查
npm test               # 核心逻辑回归测试
npm run build          # 重新生成独立成品 play.html
npm run test:balance   # 三个随机种子的完整战役模拟
# 先在另一终端运行 npm start，再运行：
npm run test:browser   # Chromium 实际界面操作测试
npm run test:offline   # 禁用网络后的单文件运行与存档测试
npm run test:stress    # 五片海域、复杂构筑与菜单回归
```

浏览器测试默认使用 `/usr/bin/chromium`；可通过 `CHROMIUM_PATH` 指定浏览器。开发测试依赖已锁定在 `package-lock.json`，成品没有外部运行时依赖。

`src/core.js` 是纯游戏逻辑，`src/render.js` 绘制原创矢量场景与角色，`src/app.js` 管理菜单、输入、合成音效和存档。所有美术和声音由本项目程序生成，无远程素材、广告或付费功能。

验证范围与结果见 [TESTING.md](TESTING.md)。
