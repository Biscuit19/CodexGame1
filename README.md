# 余响航线 · 深海远征 v7

**在线游玩：https://biscuit19.github.io/CodexGame1/**

电脑键鼠单人 2D 肉鸽射击游戏。操控机械拾光员，在随机海域中收集武器、遗物，点亮灯塔，迎战机械海生物。自动射击和辅助瞄准默认开启，可在“设置”关闭。首页版本应为 **深海远征 / 07**，旧页面可 Ctrl+F5 刷新。

## 本次更新

- **68 张透明原创图标**：按名称重画 36 件遗物；冲刺与分身使用实际机器人动作，18 种武器有独立轮廓和发射机构，航标改为更亮的灯塔。统一钢铁、薄荷绿、海蓝和黄铜配色，生成源为 `tools/icons.mjs`。
- **清楚的武器说明**：名称仅显示武器本名，类型、元素与附加词条分行说明具体效果；去除 T 等级。奖励和商店都用相同字号展示“每秒伤害”和“当前武器”。指南按低到高解释标准、稀有、史诗、传说、远古、神话。
- **战役延长到 20 关**：每关刷新窗口 25–60 秒，第 15 关双首领，第 16–19 关 1–2 位，第 20 关三首领。预先显示下一关是否有首领；计划首领在开场 10 秒出现。击败首领后仍须清掉所有小兵；战斗、清场可以超过刷新窗口。
- **更丰富的战斗**：十种动态首领增加跟踪后锁定的蓄力轨道炮、错时三连激光、快速扇射、留缺口的爆破包围、交叉轰炸。首领有快慢分工、动态肢体、独立攻击声音；战役首领血量与伤害上调。小兵后期逐渐加速，行动速度限制在玩家跑速以下；首领突进可更快。
- **反馈调整**：玩家受伤加入明显的电子冲击声；光束从枪口前方发出，降低亮度、动态伸展后衰减；减速敌人身上出现小冰块。
- **物资箱回收**：保留当前武器，将箱子兑换星币，金额随实际候选内容品质提高。其他奖励仍可放弃。清场金币、经验和箱子先飞向角色，依次领完升级、箱子与清场奖励后再进入下一关。
- **43 首完整配乐**：本次增加 20 首同一游戏原声来源的音乐，现在有 27 首常规、10 首首领、6 首事件音乐，分阶段随机轮换并淡入淡出。详细来源和许可证见 [ASSET_CREDITS.md](ASSET_CREDITS.md)。

## 玩法与存档

- 18 种武器，包括散射、追踪、穿透、回旋、激光、波形、感应雷、环射、分裂弹；元素与词条随机组合。后期解锁更高级骨架与品质。
- 36 件遗物，包括 8 件仅在后期高级池中低概率出现的高级遗物。满级遗物不会重复占奖励位；商店还可无限购买微量火力 / 生命研修，价格逐次提高。修复和救援随关卡及购买次数涨价。
- 17 类随机事件，包含单侧突袭、悬赏、共生双子、运宝卫队、脉冲哨兵、裂隙守卫等；目标清除即结束战斗事件。
- 点亮灯塔需 3.5 秒，单座有随机回报，三座全亮保证金箱与额外奖励，也可能召来特殊首领。下一条航线随机确定。
- 第 20 关通关后选择进入无尽，第 21 关开始每关 1–5 位首领，每三关增加一位，刷新窗口始终 60 秒。玩家成长受到限制，敌方额外血量与伤害逐渐指数增长，目标约第 28 关形成较大压力。具体取决于操作和构筑。
- **三个独立存档槽**：退出、切换、暂停和每 10 秒自动保存到当前槽。继续已有存档保留战斗、商店和待领奖励；新建空槽或点击重开才开始新游戏。兼容 v2–v6 存档；v6 已通关的 15 关战役可接着玩第 16 关，原有无尽存档继续无尽。存档保存在当前浏览器，清理网站数据会删除进度。

每秒伤害为当前构筑的理论输出，不计暴击、爆炸、电弧、分身与临时事件增益；穿透与环射也受命中数量影响，不能等同实战伤害。暂停与构筑页显示累计实际伤害（k）。

## 下载与运行

源码分支：`codex/echo-drift-delivery`，发布分支：`gh-pages`。

下载 `release/echo-drift.zip`（GitHub 文件页 → Download raw file），**完整解压后打开 play.html，保留旁边的 assets 文件夹**。包内入口与网页一样按需读取本地资源，43 首完整音乐均在包内，不依赖网络。这样无需在 ZIP 内重复存放两遍曲库。

仓库根目录另有约 86 MiB 的 **play.html 单文件版**，全部音乐与图标内嵌；在线 Pages 入口约 168 KiB，按需加载音乐。浏览器限制本地 HTML 时，在解压目录运行 `npm start`，访问 http://localhost:4173/ 。运行游戏需 Node.js 20+，无需安装依赖。云环境目录：`/workspace/CodexGame1`，Pages 不依赖云端进程。
