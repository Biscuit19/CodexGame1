# 余响航线 · 深海远征 v8

**在线游玩：https://biscuit19.github.io/CodexGame1/**

电脑键鼠单人 2D 肉鸽射击游戏。操控机械拾光员，在随机海域中收集武器、遗物，点亮灯塔，迎战机械海生物。自动射击和辅助瞄准默认开启，可在“设置”关闭。首页版本应为 **深海远征 / 08**，旧页面可 Ctrl+F5 刷新。

## 本次更新

- **醒目的生命 HUD**：血量数字增大到 30–34px，血条加粗到 24px，增加亮色边框，低血量变红。左下当前武器增加对应图标。
- **无需滚动的常用界面**：商店每行四件，最多八个货架；奖励卡横向展开、减小行距，品质放在“武器”标题旁。1280×720、1366×768、1440×900、1024×768、900×640 均检查全部文字和按钮可见。
- **关卡敌群特色**：冲撞群、炮火阵地、裂殖潮、重甲护卫、游猎小队随机轮换，相邻关卡不重复，实际改变敌人组成及远程怪比例。第 5 关开始增加小怪强度，第 20 关普通敌人血量约为 v7 的 2.98 倍，伤害约 1.60 倍；移速仍低于玩家。
- **更少的物资箱**：首关保留起始箱，后续起始箱概率 65%；每关最多一只额外普通补给箱。双子事件不会重复掉箱，每位计划首领仍保证自己的箱子。数值模拟平均约每关 2–3 箱，并非每关固定配额。航标改为随机单类奖励，取消同时发金币、经验及三座必出金箱。
- **成长与战斗校准**：清场增加少量经验，始终先处理升级再进入下一关。减少箱子后同步回调首领血量，降低首领战伴生敌潮刷新频率；保留十种首领攻击、20 关战役及通关后的无尽。普通难度中后期更有压力，悠游模式仍提供较宽容的完整战役。
- **两个技能各两项小幅升级**：折光步幅每级冲刺距离 +5%；应急回流每级冲刺回血 +2；回声延展每级分身持续 +0.4 秒；同步校准每级分身伤害系数 +3%。各最多三级，可从升级、物资箱、航标奖励和商店获得；满级后退出候选池。构筑页显示等级与效果。
- **奖励池与数值**：满级遗物在奖励显示、领取、刷新及读档时再次检查，替换为火力 / 船体研修；原有高级池仍按解锁条件抽取。累计伤害直接显示完整数值，去掉 k 缩写。

## 玩法与存档

- 18 种武器，包括散射、追踪、穿透、回旋、激光、波形、感应雷、环射、分裂弹；元素与词条随机组合。后期解锁更高级骨架与品质。
- 36 件遗物，包括 8 件仅在后期高级池中低概率出现的高级遗物。满级遗物不会重复占奖励位；商店还可无限购买微量火力 / 生命研修，价格逐次提高。修复和救援随关卡及购买次数涨价。
- 17 类随机事件，包含单侧突袭、悬赏、共生双子、运宝卫队、脉冲哨兵、裂隙守卫等；目标清除即结束战斗事件。
- 点亮灯塔需 3.5 秒，每次随机获得一类奖励：修复、经验、星币、随机武器、物资箱或事件；武器可以保留当前装备并改选研修。下一条航线随机确定。
- 第 20 关通关后选择进入无尽，第 21 关开始每关 1–5 位首领，每三关增加一位，刷新窗口始终 60 秒。玩家成长受到限制，敌方额外血量与伤害逐渐指数增长，目标约第 28 关形成较大压力。具体取决于操作和构筑。
- **三个独立存档槽**：退出、切换、暂停和每 10 秒自动保存到当前槽。继续已有存档保留战斗、商店和待领奖励；新建空槽或点击重开才开始新游戏。兼容 v2–v7 存档；v6 已通关的 15 关战役可接着玩第 16 关，原有无尽存档继续无尽。存档保存在当前浏览器，清理网站数据会删除进度。

每秒伤害为当前构筑的理论输出，不计暴击、爆炸、电弧、分身与临时事件增益；穿透与环射也受命中数量影响，不能等同实战伤害。暂停、构筑与结算页显示完整累计实际伤害数值。

## 下载与运行

源码分支：`codex/echo-drift-delivery`，发布分支：`gh-pages`。

下载 `release/echo-drift.zip`（GitHub 文件页 → Download raw file），**完整解压后打开 play.html，保留旁边的 assets 文件夹**。包内入口与网页一样按需读取本地资源，43 首完整音乐均在包内，不依赖网络。这样无需在 ZIP 内重复存放两遍曲库。

仓库根目录另有约 86 MiB 的 **play.html 单文件版**，全部音乐与图标内嵌；在线 Pages 入口约 183 KiB，按需加载音乐。浏览器限制本地 HTML 时，在解压目录运行 `npm start`，访问 http://localhost:4173/ 。运行游戏需 Node.js 20+，无需安装依赖。云环境目录：`/workspace/CodexGame1`，Pages 不依赖云端进程。
