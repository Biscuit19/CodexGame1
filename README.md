# 余响航线 · 深海远征 v10

**在线游玩：https://biscuit19.github.io/CodexGame1/**

电脑键鼠单人 2D 肉鸽射击游戏。操控机械拾光员，在随机海域中收集武器、遗物，点亮灯塔，迎战机械海生物。自动射击和辅助瞄准默认开启，可在“设置”关闭。首页版本应为 **深海远征 / 10**，旧页面可 Ctrl+F5 刷新。

## 本次更新

- 首领基础伤害提高 30%，基础移速提高 22%；镜师、雷翼与巨钳会按玩家当前速度追击，常规移动限制在玩家速度的 1.2 倍以内，蓄力冲撞另计。后期攻击间隔缩短、连续弹幕增至四波，弹速逐渐提升，敌弹上限仍为 80。
- 增加预判移动的横向炸弹封路、提前量冲撞与预判激光组合。爆破和冲撞在预警时锁定目标，保留变向与冲刺的反制窗口。
- 无尽首领血量与小兵倍率分离。第 28 关相同数量首领总血量比 v9 降低约 70%（先按 60% 调整，单体武器验证后进一步下调），之后缓慢增长。标准难度、满四层护甲下，第 28 关普通首领弹约 100 点伤害；激光与冲撞更高，悠游难度另有减伤。
- 早期升级奖励中遗物与基本属性约各半，少量技能强化独立抽取；早期普通箱子增加遗物候选。大多数遗物满级后更多提供基本属性。
- 商店成功购买立即播放钱袋音效；失败购买不播放。v9 战斗存档里的首领血量比例、伤害与速度会迁移一次，保留进度。

以下基本属性规则继续保留：

通用成长改为独立的“基本属性”，不再占遗物栏。射速、伤害、生命、移速、暴击率、每秒回血和技能冷却可在升级、物资箱、清场奖励中获得，商店也有基本属性货架。构筑页单独展示属性、已升级次数和实际冷却。

| 属性 | 第 1–5 次，每次增加 | 第 6 次起，每次增加 | 上限 |
|---|---|---|---|
| 射速 | 10% | 5% | 无 |
| 伤害 | 20% | 10% | 无 |
| 生命上限 | 25 | 12 | 无 |
| 移速 | 8% | 4% | 无 |
| 暴击率 | 6 个百分点 | 3 个百分点 | 无 |
| 每秒回血 | 0.25 | 0.125 | 无 |
| 技能冷却缩减 | 2 个百分点 | 2 个百分点 | 30%，15 次 |

百分比成长采用加算，不会每次复乘。例如射速升级五次为 +50%，第六次为 +55%。暴击率初始 8%，可超过 100%；超过部分用于额外暴击层级：140% 时每次至少双倍伤害，40% 概率三倍伤害。基础回血为 0.1/秒。冷却含武器和航线加成后也不会超过 30% 总缩减。

- **存档迁移**：潮光透镜、钟表发条、温暖贝壳、轻羽船靴、缓慢心跳、风暴玻璃、空白邮票、熔星反应炉、深潜核心、无王之冠退出新遗物池。旧通用加成转为基本属性中的迁移加成，已增加的生命与当前血量保留。旧日胶片保留分身持续时间效果，旧冷却收益归入冷却属性并受 30% 上限约束。旧武器校准、火力/船体研修保留已获得收益，后续升级统一使用新属性规则。迁移只执行一次。
- **激光更有分量**：视觉宽度为 v8 的 2.4 倍，保留枪口前方起点与动态渐隐；不扩大实际命中判定。高射速会在一个模拟步中发射多轮，避免只增加面板数值。
- **小型状态特效**：暴击有金色交叉闪光与火花，爆炸有短促冲击圈与放射线，灼烧敌人有橙色小火焰；冻结换成带白色雪花的实色蓝色冰块 SVG。
- **受击更清楚**：受击声提高至与射击接近的实测峰值，保留独立音效音量与静音。敌弹、红色危险提示和紧凑奖励布局继续保留。
- **无尽校准**：基本属性可以持续线性增长，相应重新校准无尽额外倍率；旧无尽存档按比例迁移一次。仍保留约第 28 关后较大压力的目标，实际结果取决于构筑与操作。

## 玩法与存档

- 18 种武器，包括散射、追踪、穿透、回旋、激光、波形、感应雷、环射、分裂弹；元素与词条随机组合。后期解锁更高级骨架与品质。
- 26 件遗物，包括 6 件仅在后期高级池中低概率出现的高级遗物。满级遗物不会重复占奖励位；奖励与商店提供可持续升级的基本属性，商店价格逐次提高。修复和救援随关卡及购买次数涨价。
- 17 类随机事件，包含单侧突袭、悬赏、共生双子、运宝卫队、脉冲哨兵、裂隙守卫等；目标清除即结束战斗事件。
- 点亮灯塔需 3.5 秒，每次随机获得一类奖励：修复、经验、星币、随机武器、物资箱或事件；武器可以保留当前装备并改选基本属性。下一条航线随机确定。
- 第 20 关通关后选择进入无尽，第 21 关开始每关 1–5 位首领，每三关增加一位，刷新窗口始终 60 秒。玩家成长受到限制，小兵额外血量与伤害逐渐指数增长，首领改用独立缓增长血量与递增伤害，目标约第 28 关形成较大压力。具体取决于操作和构筑。
- **三个独立存档槽**：退出、切换、暂停和每 10 秒自动保存到当前槽。继续已有存档保留战斗、商店和待领奖励；新建空槽或点击重开才开始新游戏。兼容 v2–v9 存档；v6 已通关的 15 关战役可接着玩第 16 关，原有无尽存档继续无尽。存档保存在当前浏览器，清理网站数据会删除进度。

每秒伤害为当前构筑的理论输出，不计暴击、爆炸、电弧、分身与临时事件增益；穿透与环射也受命中数量影响，不能等同实战伤害。暂停、构筑与结算页显示完整累计实际伤害数值。

## 下载与运行

源码分支：`codex/echo-drift-delivery`，发布分支：`gh-pages`。

下载 `release/echo-drift.zip`（GitHub 文件页 → Download raw file），**完整解压后打开 play.html，保留旁边的 assets 文件夹**。包内入口与网页一样按需读取本地资源，43 首完整音乐均在包内，不依赖网络。这样无需在 ZIP 内重复存放两遍曲库。

仓库根目录另有约 86 MiB 的 **play.html 单文件版**，全部音乐与图标内嵌；在线 Pages 入口约 190 KiB，按需加载音乐。浏览器限制本地 HTML 时，在解压目录运行 `npm start`，访问 http://localhost:4173/ 。运行游戏需 Node.js 20+，无需安装依赖。云环境目录：`/workspace/CodexGame1`，Pages 不依赖云端进程。
