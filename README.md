# 余响航线 · 深海交锋 v4

单人 2D 俯视角射击肉鸽：移动、瞄准、冲刺与自主瞄准分身，挑战随机海域和多首领战斗。

**在线游玩：https://biscuit19.github.io/CodexGame1/**

建议电脑、鼠标和键盘，1280×800 以上分辨率。首页右上显示“深海交锋 / 04”；若看到旧版请 Ctrl+F5 刷新。兼容 v2/v3 存档，自动更新规则与商店价格。存档在当前浏览器，清除网站数据会删除进度。

## 本次更新

- **更短的航段**：普通敌潮刷新窗口 25–60 秒，最终关 90 秒。倒计时结束停止刷新，必须消灭全部敌人再过关；实际清场和首领战可超过刷新窗口。击败首领仍需清掉所有小兵。
- **最终双首领**：最后一关同时出现两位常规首领。后期小兵、悬赏和首领血量提高；首领移动加快，增加分层弹幕、定向追击和更频繁的物理攻击。每种攻击有不同音效。
- **无尽模式**：每关至少一位首领，每三关增加一位，最多五位。刷新窗口按数量为 60、67.5、75、82.5、90 秒，多首领共享调整后的遭遇血量预算，避免单纯叠血拖长战斗。
- **明确的危险色**：敌弹与延迟攻击圈为红色，爆破中心是红色三角警告图案。小地图放大，敌人和首领标记更清晰。
- **清楚的装备信息**：商店武器标明稀有度、T 等级与构筑直击 DPS，遗物标明品质；武器和遗物常规价格提高到 420 / 280 星币，商队折扣为 300 / 200。构筑页明确展示当前武器、单发伤害、射速、DPS 和遗物列表。
- **更多物资**：物资箱可提供武器、遗物、经验、星币、治疗、生命上限、伤害校准、技能芯片与救援。金箱保证包含一项传说武器选择。满血、救援上限、校准上限等会影响可选池。
- **清楚的奖励来源**：大标题直接写“升级奖励”“物资箱奖励”“击败首领 · 航段清场奖励”，卡片以大字显示奖励类别。下一条航线由系统随机确定，关间可购物后直接出发。
- **自动收取动画**：清场后播放约 1.3 秒的金币、经验汇入角色动画，全部结算后再选奖励。初始拾取半径从 100 提高到 170，吸取中也能保存和恢复。
- **信标随机回报**：每座信标增加随机星币，并可能掉落普通箱或金箱；三座全亮保证金箱、100 星币和额外经验，还可能触发裂隙守卫或额外补给。占领仍需 3.5 秒。
- **17 类事件**：增加运宝卫队、共生双子、脉冲阵列、裂隙守卫、沉船金库、超载供能、陨星风暴。新增运宝者、护卫、双子、哨兵、裂隙守卫五种特殊变体。战斗事件在目标死亡后结束，不再空挂倒计时；限时悬赏仍保留逃离规则。
- **醒目的事件与技能 UI**：事件先在中央显示大标题，再移到左侧红字栏。冲刺和分身各有大图标、灰色冷却遮罩、恢复进度与就绪闪光。
- **23 首完整配乐**：来自 0 A.D. 的 15 首常规曲、5 首首领曲、3 首事件曲，按进度分组随机轮换、淡入淡出、统一响度。详情与许可见 [ASSET_CREDITS.md](ASSET_CREDITS.md)。

DPS 是当前构筑的理论直击输出，不计暴击、穿透、爆炸、分身和临时事件增益，不能直接等同于实际战斗总伤害。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准 / 持续射击 | 鼠标移动 / 按住左键 |
| 冲刺 | Shift / 空格 |
| 分身（复刻移动、自主瞄准） | Q / 鼠标右键 |
| 宝箱 / 附近商店 | E |
| 中央商店 | 靠近后按 B |
| 暂停 / 构筑 | Esc / Tab |
| 选择奖励 | 鼠标 / 数字 1、2、3 |

设置可开启自动射击、辅助瞄准、减少闪光和震动，并独立调整音乐和音效。分身即便没有射击记录也会自主攻击。

## 下载与运行

源码在 `codex/echo-drift-delivery`，线上发布产物在 `gh-pages`。
下载 `release/echo-drift.zip`（GitHub 文件页 → Download raw file），解压后打开 `play.html` 离线游玩。完整音乐已内嵌，单文件约 48.4 MiB，首次打开需要加载，之后不请求外部素材。

浏览器限制本地 HTML 时，在解压目录执行 `npm start`，访问 http://localhost:4173/ 。仅运行游戏需 Node.js 20+，无需安装依赖。云环境目录：`/workspace/CodexGame1`。Pages 不依赖云端服务持续运行。
