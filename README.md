# 余响航线 · 灵动回声 v3

单人 2D 俯视角射击肉鸽。移动、瞄准、折光冲刺与复刻自己行动的回声，在随机海域中挑战五座灯塔。

**在线游玩：https://biscuit19.github.io/CodexGame1/**

建议电脑、鼠标和键盘，1280×800 或更高分辨率。若仍看到旧版，请 Ctrl+F5 刷新。v3 自动兼容上一版 v2 存档；存档保存在当前浏览器，清除网站数据会删除进度。

## 本次更新

- 敌群常规刷新频率降低 30%，突袭人数按 70% 缩减，同时降低远程种类比例。敌弹最多同时 80 发；常见远程敌人的连发量与射击频率同步降低。默认标准难度，也可选轻松难度。
- 15 个航段，前四段敌潮持续 40、50、60、65 秒，后续逐步增加，刷新窗口最多 150 秒。计时结束只停止刷新，场上敌人全部消灭后才过关，因此清场与首领战可超过 150 秒。完整自动模拟约 22 分钟战斗时间，真人选择奖励和购物会增加时长。
- 17 类敌人、随机强化词缀和 5 位首领：跳跃、冲锋、狙击、环绕射击、治疗、分裂、布雷、偷币等。
- 10 类随机事件，包括有预警的单侧突袭、两侧夹击、雷区和限时悬赏。悬赏精英出现 35 秒，击败可获得星币及传奇宝箱，超时逃离。
- 武器由枪型、元素、改件、稀有度组合生成；路线、遗物、敌群组成和掉落均随机。
- 每三段一位首领，必须真正击败。首领死亡后也要清掉剩余小怪。清场阶段停止随机刷新和召唤增援，已预警的突袭仍会抵达；远程敌人会靠近玩家。五位首领分别拥有冲撞、跃击、震地、镜面突进和潮龙俯冲，并有动作预警、恢复间隙与粒子效果。
- 通关后可保留构筑进入无尽模式，敌人继续增强，每段刷新窗口仍至多 150 秒，再进入清场。
- 中央星币商店与关间商店：治疗、永久强化当局伤害、救援、随机遗物和高级武器；还可付费刷新商品或升级奖励。
- 统一的简洁动态矢量角色，瞄准转向、步行动画、枪口后坐与首领独立动作；取消敌人周围的常驻圆圈，以角色自身边缘描线区分。HUD 关键文字放大至 18–27px；涨潮变蓝并增强波浪，退潮显露暖色浅滩。
- 五首轻快平台游戏背景曲，随海域和危险事件切换；撤下旧的诡异战斗曲。音乐统一响度并降低默认音量，射击音效增强，新增独立音效音量。旧设置会自动迁移到较低音乐音量。
- 信标占领从 8 秒缩短为 3.5 秒，回声路线进一步缩短。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD / 方向键 |
| 瞄准、射击 | 鼠标移动、按住左键 |
| 折光冲刺（短暂无敌） | Shift / 空格 |
| 余响复写 | Q / 鼠标右键 |
| 宝箱 / 附近商店 | E |
| 中央商店（靠近后） | B |
| 暂停 | Esc |
| 查看构筑 | Tab |
| 选择奖励 | 鼠标 / 数字 1、2、3 |

回声分身循环复刻最近 4 秒的移动，独立自动瞄准 800 范围内的最近敌人。即便玩家没有射击记录，分身也会开火；无敌人时停火。设置可开启自动射击、辅助瞄准、减少闪光和震动。音乐需点击开始后播放，符合浏览器自动播放限制。

## 下载与运行

源码在 `codex/echo-drift-delivery` 分支，Pages 产物在 `gh-pages` 分支。
下载 `release/echo-drift.zip`（GitHub 文件页的 Download raw file），解压后打开 `play.html` 即可离线游玩。也可直接下载单文件 `play.html`。音乐与图片全部内嵌，因此单文件约 6.4 MiB。

若浏览器限制本地 HTML，在解压目录执行：

```bash
npm start
```

访问 http://localhost:4173/ 。运行只需 Node.js 20+，无需安装依赖。云环境路径为 `/workspace/CodexGame1`；线上网站不依赖云环境服务是否运行。
